ส่งรายการจากหน้าร้านเข้าครัว

กดส่งครัว ให้ทีมครัวเห็นรายการที่ต้องทำและทำเครื่องหมายเมื่อพร้อมเสิร์ฟ

ทานด้วยกัน แต่อยากแยกจ่าย

ใช้การแยกบิลตอนคิดเงิน พร้อมเก็บยอดขายกลับมาดูในรายงาน

เลือกร้านอาหาร · โต๊ะ หน้าจอครัว และแยกบิล เริ่มที่ Lite

  1. 01 / รับรายการเริ่มจากออเดอร์

    เลือกสินค้าและเก็บรายละเอียดที่ลูกค้าต้องการ

  2. 02 / จัดเตรียมรู้ว่าต้องทำอะไรต่อ

    ร้านอาหารส่งรายการเข้าครัว ร้านค้าจัดสินค้าให้ลูกค้า

  3. 03 / รับเงินจบบิลให้ชัดเจน

    เลือกวิธีรับเงิน ยืนยันรายการ และออกใบเสร็จ

  4. 04 / ปิดร้านกลับมาดูยอดของวัน

    ตรวจรายการขายและยอดรับเงินก่อนปิดยอด
