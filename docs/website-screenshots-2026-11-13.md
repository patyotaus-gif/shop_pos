เก็บไฟล์ภาพรุ่นก่อนเพื่อรองรับหน้าเว็บที่ยังถูกแคช แต่ไม่มีหน้า HTML อ้างอิงภาพเก่าแล้ว

## การจัดข้อมูลและคืนค่าเครื่อง

- ตะกร้าชั่วคราวถูกล้างจนเหลือ 0 รายการหลังถ่าย ไม่มีการชำระเงิน
- สร้างออเดอร์ตัวอย่างรอชำระเพียงรายการเดียว ตรวจชื่อร้านทดสอบก่อนสร้าง
  ลบเฉพาะรายการที่มีรหัสงานนี้และยังไม่ชำระ แล้วอ่านกลับยืนยันว่าไม่มีรายการเหลือ
- ไม่เปลี่ยนยอดขาย สต็อก หรือสถานะงานครัว ภาพครัวแสดงใบงานทดสอบเดิม
  วันที่รับออเดอร์ในภาพจึงเก่ากว่าวันถ่ายภาพ ไม่ใช่รุ่นแอปเก่า
- ไม่สร้างยอดขายเพื่อโฆษณา ภาพรวมแสดงศูนย์ตามข้อมูลจริง
- ไม่เผยแพร่อีเมล เบอร์โทร หรือชื่อลูกค้าจริงในภาพที่เลือก
- ปรับ density เป็น 400 ชั่วคราว และ 540 สำหรับจอครัวเพื่ออ่านใบงานได้ชัด
  พร้อมซ่อนแถบระบบและ S Pen ขณะถ่าย ภายหลังคืน density 320,
  policy_control เป็น null และ air_button_onoff เป็น 1 ตรวจค่ากลับแล้ว
- คืนแอปไปหน้าทานที่ร้าน/สั่งกลับบ้าน ภาพอาหารใช้ชุดที่มาบันทึกไว้ใน
  [เอกสารภาพวันที่ 11 พฤศจิกายน](website-screenshots-2026-11-11.md)

## แก้ภาพครัวให้ตรงกับแท็บเล็ต — เผยแพร่และตรวจแล้ว

เจ้าของพบว่าครัวบนแท็บเล็ตมีสองคอลัมน์ แต่ภาพเว็บมีคอลัมน์เดียว สาเหตุคือ
ภาพครัวรอบแรกถ่ายที่ density 540 เพื่อขยายข้อความ ทำให้พื้นที่ใช้งานเชิงตรรกะ
แคบลงจนแอปเปลี่ยนเป็นคอลัมน์เดียวตามการออกแบบ responsive ไม่ใช่แอปรุ่นเก่า
หรือเว็บยุบคอลัมน์ของภาพเอง

- ถ่ายใหม่จาก SM-X900 แอป 1.2.78 (95) ที่ density ปกติ 320 แนวนอน โดยไม่เปลี่ยน density
- ใช้ภาพต้นฉบับ 2960 × 1848 ทุกไบต์ พร้อมชื่อใหม่ `kitchen-1.2.78-tablet.png`
  แทนทั้งภาพย่อและลิงก์ภาพเต็มในหน้าแรกและหน้าร้านอาหาร
- ตรวจภาพจริงและตำแหน่งรายการอาหารสองโต๊ะจาก UI hierarchy: อยู่แถวเดียวกัน
  และพื้นที่ไม่ทับกัน จึงยืนยันสองคอลัมน์จากอุปกรณ์จริงได้
- ซ่อนแถบระบบชั่วคราว คืน policy_control เป็น null และค่า S Pen เป็น 1 แล้ว
  ไม่มีการแก้ข้อมูลร้าน สั่งพิมพ์ หรือเปลี่ยนสถานะออเดอร์
- ตรวจในเบราว์เซอร์สองหน้า × ความกว้าง 390/768/1440 ภาพโหลดครบ คงสัดส่วน
  ไม่ล้นแนวนอน และกดเปิดภาพขนาดเต็มได้ครบทั้งหกกรณี
- หลักฐานภาพต้นฉบับ UI hierarchy การคืนค่าเครื่อง และภาพเว็บ:
  `D:/pokpok-kitchen-two-columns-20261113/`
- หลักปฏิบัติต่อไป: ภาพโฆษณาต้องรักษารูปแบบการจัดหน้าจอที่ใช้งานจริง
  ไม่ขยาย density เพื่อให้อ่านง่ายจนเปลี่ยนจำนวนคอลัมน์; ใช้ลิงก์ภาพเต็มช่วยแทน
