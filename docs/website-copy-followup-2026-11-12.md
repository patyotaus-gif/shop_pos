## ข้อความที่ปรับ

| จุด | ข้อความใหม่ |
| --- | --- |
| Solo — การขาย | ระบบขายสินค้าและรับชำระเงิน |
| Solo — รายงาน | รายงานสรุปยอดขายประจำวัน |
| Lite — สินค้า | จัดการสินค้าคงเหลือและแจ้งเตือนสินค้าใกล้หมด |
| Lite — ยอดค้าง | จัดการยอดค้างชำระและบันทึกการรับชำระ |
| Full — พนักงาน | รองรับบัญชีผู้ใช้งานสำหรับพนักงาน 3 บัญชี |
| Full — สมาชิก | ระบบสมาชิกและสะสมคะแนน |
| Full — รายงาน | รายงานวิเคราะห์ข้อมูลการขาย |
| ค่าใช้จ่าย | รายละเอียดค่าใช้จ่ายและเงื่อนไขการให้บริการ |
| FAQ | คำถามที่พบบ่อยเกี่ยวกับการใช้งาน Pokpok |

ส่วนค่าใช้จ่ายระบุชัดว่าแพ็กเกจเป็นค่าซอฟต์แวร์ ไม่รวมอุปกรณ์เพิ่มเติม
และค่าธรรมเนียมจากผู้ให้บริการรับชำระเงินภายนอก พร้อมแนะนำให้ตรวจเงื่อนไขก่อนสมัคร
ยังมีช่องทางสอบถามเรื่องหลายสาขาและบัญชีพนักงานเพิ่มเติม

FAQ ใช้คำถามตรงประเด็นเกี่ยวกับประเภทธุรกิจ อินเทอร์เน็ต การเปลี่ยนอุปกรณ์
การทดลองใช้ และการหมดอายุแพ็กเกจ เพิ่มลิงก์อีเมลและ LINE สำหรับสอบถาม
คำตอบเรื่องหมดอายุเลิกใช้คำรับรองว่าข้อมูลอยู่ครบตลอดไป
โดยอธิบายการแสดงหน้าต่ออายุและการกลับเข้าใช้ด้วยบัญชีเดิม
อ้างอิง `lib/widgets/subscription_gate.dart` และการต่ออายุใน `functions/subscription_payment.js`

## ศัพท์ที่ใช้ร่วมกัน

| ใช้ในคำอธิบาย | หมายเหตุ |
| --- | --- |
| แอป | ใช้การสะกดเดียวกันในหน้าเว็บและคู่มือ |
| สินค้าคงเหลือ | ใช้อธิบายจำนวนสินค้า; คงชื่อเมนูจริงและคำค้น “สต็อก” ได้ |
| คำสั่งซื้อ | คงชื่อเมนู “ออเดอร์” ในขั้นตอนที่ต้องกดตามแอป |
| ผู้จำหน่าย | ใช้แทนร้านส่งในเมนูและคำอธิบาย Marketplace |
| รับชำระเงิน | ไม่เปลี่ยนชื่อเอกสาร “ใบเสร็จรับเงิน” |
| รายการขาย | ไม่เปลี่ยนชื่อเอกสารหรือชื่อเมนูที่อ้างอิงจริง |
| หน้าจอครัว | บอกปลายทางของรายการอาหารให้ชัด |

ยังค้นหาคู่มือด้วยคำว่า “ออเดอร์” และ “ร้านส่ง” ได้
ปรับข้อความซ้ำในหน้าแรก หน้าราคา ฟีเจอร์ คู่มือ บทความ และส่วนท้ายให้สอดคล้องกัน
หน้า Privacy/Terms แก้เฉพาะเมนู ส่วนท้าย และเวอร์ชันสคริปต์; ไม่แก้เนื้อหานโยบาย

ราคายังคง 199 / 399 / 599 บาทต่อเดือน และ 1,990 / 3,990 / 5,990 บาทต่อปี
การทดลองใช้และสิทธิ์แพ็กเกจไม่เปลี่ยน ไม่มีการแก้แอป ระบบรับชำระเงิน หรือฐานข้อมูล
ข้อความแพ็กเกจทั้ง HTML และ JavaScript ใช้ชุดเดียวกัน
อัปเดต query ของ `site.js` เป็น `v=20261112-terms` เพื่อให้โหลดข้อความใหม่เมื่อเผยแพร่

## ผลตรวจภายในเครื่อง

- `scripts/test_marketing_pages.cjs`: ผ่าน (exit 0) ครบ 16 หน้า × 5 ความกว้าง
  320 / 390 / 768 / 1024 / 1440 พิกเซล ครอบคลุมลิงก์และไฟล์ภาพ หัวข้อ/ID
  การล้นจอ เมนู/Escape สลับแพ็กเกจ การค้นหาและหมวดคู่มือ FAQ และเนื้อหาเมื่อปิด JavaScript
- ตรวจเพิ่มเติม 48 สถานะของหน้าแรกและหน้าราคา ที่ 320 / 390 / 1440 พิกเซล:
  ข้อความการ์ดและคำตอบ FAQ ไม่ล้นหรือตัด สลับประเภทร้านและรายเดือน/รายปีได้
  ราคาเดิม ข้อความ HTML ตรงกับ JavaScript และตรงกันระหว่างหน้าแรกกับหน้าราคา
  ตรวจข้อความแพ็กเกจเมื่อปิด JavaScript และคำค้นเดิมของคู่มือด้วย
- เครื่องมือตรวจเพิ่มเติมรอบแรกพบการเทียบช่องว่างของ HTML กับข้อความที่ JavaScript สร้าง
  จึงแก้เครื่องมือตรวจให้เทียบแต่ละรายการ `li` แทนทั้ง `ul`; รอบถัดไปผ่าน
  ไม่ใช่ความผิดพลาดของข้อความในเว็บ
- ตรวจภาพการ์ดแพ็กเกจ ค่าใช้จ่าย และ FAQ บนมือถือจำลองกับจอใหญ่ด้วยสายตา
  หลักฐานอยู่ที่ `D:/pokpok-copy-followup-20261112/`
- `git diff --check`: ผ่าน ไม่มีการทดสอบบนมือถือหรือแท็บเล็ตจริงในรอบนี้
