เกลาบางประโยคให้กระชับสำหรับมือถือ รวมข้อเสนอส่งรายการเข้าครัวที่ซ้ำกัน
และใช้ “งานร้านค้า” แทน “ทุกกระบวนการ” เพื่อไม่ให้สื่อว่ารองรับทุกงานโดยไม่มีเงื่อนไข
คำอธิบายว่าร้านแบบใดเหมาะกับแพ็กเกจปรับตามคลิปด้วย

หน้าแรกและหน้าราคามีข้อความแพ็กเกจทั้งใน HTML และ JavaScript
จึงปรับทั้งสองจุดให้ตรงกัน รวมถึงข้อความหน้าแรกสำหรับผลค้นหาและการแชร์ลิงก์
อัปเดตเวอร์ชัน URL สคริปต์ของสองหน้าที่มีการ์ดราคาเพื่อหลีกเลี่ยงข้อความเดิมจากแคช

ราคา ฟังก์ชันแต่ละแพ็กเกจ เงื่อนไขทดลอง 60 วัน ไม่ต้องผูกบัตร
สถานะ iOS ผ่าน TestFlight และเงื่อนไขค่าใช้จ่ายภายนอกยังคงเดิม
ไม่มีการแก้แอป ระบบรับชำระเงิน หรือข้อมูลร้าน
