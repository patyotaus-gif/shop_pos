# ขายเงินสดเมื่ออินเทอร์เน็ตขัดข้อง

รองรับตั้งแต่ Android 1.2.29 เตรียมข้อมูลขณะออนไลน์ก่อนใช้งานแต่ละกะ

1. เข้าสู่ระบบเจ้าของหรือพนักงานตามปกติ แล้วเปิดหน้าขายโดยไม่มีสินค้าในตะกร้าหรือบิลออนไลน์รอยืนยัน
2. กด **ขายออฟไลน์ / บิลค้าง → เตรียมข้อมูลและตั้ง PIN** ตั้ง PIN ออฟไลน์ 6–8 หลัก
3. ใช้หน้าขายเงินสดออฟไลน์ได้ถึงเวลาที่แสดง สูงสุด 12 ชั่วโมง สิทธิ์ไม่เกินวันหมดอายุของแผนร้าน
4. เมื่อเปิดแอปใหม่ เข้าเมนูเดียวกันจากหน้าเข้าสู่ระบบหรือหน้าเลือกผู้ใช้ เลือกผู้ใช้ที่เตรียมไว้แล้วกรอก PIN ออฟไลน์
5. เมื่อเน็ตกลับมา เปิดแอปและเข้าสู่บัญชีร้านเดิม ระบบลองส่งบิลทุก 30 วินาที หรือกดปุ่มซิงก์ ดูผลใน **บิลในเครื่อง**

PIN ออฟไลน์เปิดได้เฉพาะหน้าขายเงินสด ไม่เปิดเมนูเจ้าของ การใช้ PIN ผิด 5 ครั้งจะล็อก 5 นาที การถอนสิทธิ์พนักงานจากระยะไกลไม่สามารถส่งถึงเครื่องที่ขาดการเชื่อมต่อได้ทันที สิทธิ์ที่เตรียมไว้จึงมีเวลาจำกัด

บิลบันทึกในเครื่องก่อนแสดงใบเสร็จ และเก็บรหัสเดิมเมื่อส่งซ้ำ เงินทอนและราคาตัวเลือกคำนวณจากข้อมูลตอนเตรียมออฟไลน์ บิลที่ส่งสำเร็จจึงปรากฏในรายงานส่วนกลางตามเวลาขายเดิม

หากราคาเปลี่ยน สต็อกชนกับเครื่องอื่น สินค้าถูกลบ หรือสิทธิ์เปลี่ยน ระบบเก็บบิลที่รับเงินแล้วพร้อมข้อความให้ตรวจสอบในหน้ารายงานและบิลในเครื่อง สต็อกอาจติดลบได้เมื่อหลายเครื่องขายระหว่างขาดการเชื่อมต่อ สินค้าที่ใช้สูตรวัตถุดิบต้องตรวจสูตรและยอดตัดวัตถุดิบตอนซิงก์ด้วย

บิลที่เซิร์ฟเวอร์ปฏิเสธเพราะข้อมูลไม่ถูกต้องจะคงอยู่ในเครื่องพร้อมสถานะ **ต้องตรวจสอบ** ห้ามรับเงินซ้ำเพื่อแก้สถานะนี้

ช่วงออฟไลน์รองรับเงินสด ไม่มีส่วนลด ขายเชื่อ หรือสะสมแต้ม ไม่ยืนยันยอดโอน/QR และไม่ส่งงานโต๊ะ/ครัวข้ามเครื่อง ใบเสร็จใช้แบบออฟไลน์และฟอนต์ที่อยู่ในแอป การพิมพ์ยังขึ้นอยู่กับเครื่องพิมพ์และการเชื่อมต่อภายในร้าน

ก่อนถอนแอป ล้างข้อมูล หรือย้ายเครื่อง ต้องซิงก์บิลค้างให้ครบ ข้อมูลที่ยังอยู่เฉพาะเครื่องไม่ใช่ข้อมูลสำรองบนคลาวด์
